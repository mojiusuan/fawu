## 二、演示场景

### 场景 1：合同审查（约 3 分钟）

```
1. 侧边栏选择"📄 合同管理"
2. 点击"上传"标签页
3. 合同名称输入"买卖合同"，类型选"买卖合同"
4. 粘贴 data/contracts/买卖合同示例.txt 的内容
5. 点击"上传合同"
6. 复制显示的合同 ID
7. 切换到"审查"标签页，粘贴 ID
8. 点击"开始审查"
9. 观察 AI 逐条分析：
   - 🔴 高风险：违约金日千分之五 → 民法典第585条
   - 🟡 中风险：管辖约定不对等
   - 🟢 低风险：格式规范问题
10.展开每条查看法律依据和修改建议
```

**讲解要点：** RAG 检索如何找到相关法条 · 风险等级判定依据 · 审计日志记录完整决策链

### 场景 2：智能咨询（约 2 分钟）

```
1. 侧边栏选择"💬 智能咨询"
2. 输入"违约金约定多少算过高？怎么调整？"
3. AI 返回：
   - 引用民法典第 585 条
   - 解释"过分高于"的司法标准（超过损失30%）
   - 展示检索到的法律来源
4. 追问"如何申请法院调整违约金？"
5. AI 保持上下文，给出程序性建议
6. 点击侧边栏快捷问题测试其他场景
```

**讲解要点：** RAG 混合检索原理 · 引用可追溯性 · 安全护栏如何防止编造法条

### 场景 3：知识图谱（约 2 分钟）

```
1. 侧边栏选择"🔍 知识图谱"
2. 查看图谱统计：8种实体类型、12种关系、15条法条、2份判例
3. 点击"本体结构"标签页，展示实体关系定义
4. 点击"关系追溯"标签页，查看判例引用链
5. 打开 Neo4j Browser (Desktop → Open Browser)
6. 运行: MATCH (n)-[r]->(m) RETURN n, r, m LIMIT 50
7. 展示可视化节点关系图
```

**讲解要点：** 知识图谱本体模型设计 · LLM 自动抽取过程 · 图谱关联推理能力

### 场景 4：RPA 自动化（约 1 分钟）

```
1. 侧边栏选择"🤖 自动化工具"
2. 上传 data/contracts/买卖合同示例.txt
3. 点击"提取关键信息"
4. 展示提取结果：
   - contract_title: 买卖合同
   - party_a: XX贸易有限公司
   - amount: 50万元
   - dispute_resolution: 甲方住所地人民法院诉讼
```

## 四、快速恢复环境

```powershell
# 1. 环境
cd d:\babyhomework\fawu\system
venv\Scripts\activate

# 2. 配置（首次）
copy .env.example .env
# 填入 DEEPSEEK_API_KEY=sk-xxx

# 3. 安装
pip install -r requirements.txt

# 4. 初始化知识库 + 图谱（首次）
# 先确保 Neo4j Desktop 中 DBMS 已启动
python scripts/init_knowledge_base.py

# 5. 启动
python -m src.main
# → http://localhost:8080
```
