# 智能法务系统 — 数据库设计表结构

> 当前系统采用 JSON 文件存储，以下表结构为逻辑设计，字段长度基于实际数据估算。

---

## 1. 用户表 (`users_store.json`)

| 字段名 | 数据类型 | 长度 | 可否空 | 注 | 含义 |
|--------|---------|------|--------|-----|------|
| id | VARCHAR | 8 | NOT NULL | PK，UUID前8位 | 用户唯一标识 |
| username | VARCHAR | 32 | NOT NULL | UK，登录名 | 登录用户名 |
| display_name | VARCHAR | 64 | NOT NULL | 展示用 | 用户显示名称 |
| hashed_password | VARCHAR | 256 | NOT NULL | BCrypt加密 | 密码哈希值 |
| role | VARCHAR | 16 | NOT NULL | 枚举值 | 角色：admin/legal/business/auditor |
| created_at | DATETIME | — | NOT NULL | ISO8601格式 | 账号创建时间 |

**索引**：id (PK), username (UK)

---

## 2. 合同表 (`contracts_store.json`)

| 字段名 | 数据类型 | 长度 | 可否空 | 注 | 含义 |
|--------|---------|------|--------|-----|------|
| id | VARCHAR | 8 | NOT NULL | PK，UUID前8位 | 合同唯一标识 |
| title | VARCHAR | 256 | NOT NULL | — | 合同标题名称 |
| contract_type | VARCHAR | 32 | NOT NULL | 枚举值 | 合同类型：买卖/租赁/服务/劳动/借款/其他 |
| party_a | VARCHAR | 128 | NULL | 可空 | 甲方名称 |
| party_b | VARCHAR | 128 | NULL | 可空 | 乙方名称 |
| content | TEXT | — | NOT NULL | 合同全文 | 合同完整文本内容 |
| review_status | VARCHAR | 16 | NOT NULL | 枚举值 | 审查状态：未审查/已审查 |
| clauses | JSON[] | — | NULL | 数组 | 解析后的合同条款列表 |
| created_at | DATETIME | — | NOT NULL | ISO8601格式 | 合同创建时间 |

**索引**：id (PK)

**clauses 子结构**：

| 字段名 | 数据类型 | 含义 |
|--------|---------|------|
| clause_number | VARCHAR(16) | 条款编号，如"第1条" |
| content | TEXT | 条款原文 |
| risk_level | VARCHAR(16) | 风险等级：high/medium/low/none |
| risk_analysis | TEXT | 风险分析说明 |
| law_basis | VARCHAR(512) | 法律依据引用 |
| suggestion | TEXT | 修改建议 |

---

## 3. 咨询历史表 (`consultation_history.json`)

| 字段名 | 数据类型 | 长度 | 可否空 | 注 | 含义 |
|--------|---------|------|--------|-----|------|
| id | VARCHAR | 8 | NOT NULL | PK，UUID前8位 | 咨询记录唯一标识 |
| question | TEXT | — | NOT NULL | 用户原始输入 | 用户提出的法律问题 |
| answer_summary | TEXT | — | NULL | AI回答摘要（前200字） | AI生成的回答概要 |
| timestamp | DATETIME | — | NOT NULL | ISO8601格式 | 咨询时间 |

**索引**：id (PK)

**注**：完整 AI 回答通过 audit_id 关联审计日志追溯，answer_summary 仅存储摘要用于历史列表展示。

---

## 4. 文书模板表 (`doc_templates.json`)

| 字段名 | 数据类型 | 长度 | 可否空 | 注 | 含义 |
|--------|---------|------|--------|-----|------|
| template_id | VARCHAR | 64 | NOT NULL | PK | 模板唯一标识 |
| category | VARCHAR | 32 | NOT NULL | 枚举值 | 模板分类：起诉类/答辩类/申请类/协议类 |
| title | VARCHAR | 256 | NOT NULL | — | 模板名称 |
| description | TEXT | — | NULL | — | 模板用途说明 |
| required_fields | JSON[] | — | NOT NULL | 数组 | 模板所需填写字段定义 |
| template_content | TEXT | — | NOT NULL | 含{{占位符}} | 模板正文 |
| download_count | INT | — | NOT NULL | 默认0 | 下载次数 |

**索引**：template_id (PK)

**required_fields 子结构**：

| 字段名 | 数据类型 | 含义 |
|--------|---------|------|
| key | VARCHAR(32) | 占位符键名，如 plaintiff_name |
| label | VARCHAR(64) | 字段显示标签 |
| type | VARCHAR(16) | 输入类型：text/date/select |
| required | BOOLEAN | 是否必填 |

---

## 5. 专题库表 (`topic_libraries.json`)

| 字段名 | 数据类型 | 长度 | 可否空 | 注 | 含义 |
|--------|---------|------|--------|-----|------|
| topic_id | VARCHAR | 32 | NOT NULL | PK | 专题唯一标识 |
| title | VARCHAR | 128 | NOT NULL | — | 专题名称 |
| description | TEXT | — | NULL | — | 专题内容描述 |
| icon | VARCHAR | 8 | NULL | Emoji字符 | 专题图标 |
| laws | JSON[] | — | NOT NULL | 数组 | 相关法律法规列表 |
| faq | JSON[] | — | NOT NULL | 数组 | 常见问题与解答 |

**索引**：topic_id (PK)

**laws 子结构**：name (法规名称), key_articles (重点法条列表)

**faq 子结构**：q (问题), a (回答)

---

## 6. 审计日志 (`logs/` — 追加写入文件)

| 字段名 | 数据类型 | 长度 | 可否空 | 注 | 含义 |
|--------|---------|------|--------|-----|------|
| audit_id | VARCHAR | 8 | NOT NULL | PK，UUID前8位 | 审计记录唯一标识 |
| timestamp | DATETIME | — | NOT NULL | ISO8601 UTC | 操作时间戳 |
| user_id | VARCHAR | 8 | NULL | 匿名用户为空 | 操作用户标识 |
| task_type | VARCHAR | 32 | NOT NULL | 枚举值 | 任务类型：contract_review/consultation/rag_query/rpa/kg_query |
| model | VARCHAR | 64 | NOT NULL | — | 使用的LLM模型名称 |
| input_summary | TEXT | — | NULL | 截断存储 | 输入内容摘要 |
| output_summary | TEXT | — | NULL | 截断存储 | 输出内容摘要 |
| token_count | INT | — | NULL | — | 消耗Token数 |
| latency_ms | INT | — | NULL | — | 响应延迟（毫秒） |

**索引**：audit_id (PK), timestamp（按日分文件）

**存储特点**：每条日志一行JSON，每日一个文件，追加写入不可删除，SHA256脱敏敏感信息。

---

## 7. 计算规则表 (`fee_rules.json` / `compensation_rules.json` / `limitation_rules.json`)

| 字段名 | 数据类型 | 长度 | 可否空 | 注 | 含义 |
|--------|---------|------|--------|-----|------|
| rule_type | VARCHAR | 32 | NOT NULL | 枚举值 | 规则类型：fee/compensation/limitation |
| rule_content | JSON | — | NOT NULL | 嵌套结构 | 规则具体参数与计算公式 |

**注**：三个文件合并为一张逻辑表，rule_type 区分规则类别。均为系统预置的只读参考数据，不随用户操作变更。

---

## 8. 案件与证据指引表 (`case_types.json` / `evidence_guides.json`)

| 字段名 | 数据类型 | 长度 | 可否空 | 注 | 含义 |
|--------|---------|------|--------|-----|------|
| case_type | VARCHAR | 32 | NOT NULL | 枚举值 | 案件类型：labor/loan/injury/marriage/consumer/property/contract |
| type_config | JSON | — | NOT NULL | 案件要素定义 | 该类型案件的构成要件与分析模板 |
| evidence_guide | JSON | — | NOT NULL | 证据清单 | 该类型案件的证据收集指引 |

**注**：系统预置的只读参考数据。case_types 定义案件分类与要素，evidence_guides 按类型给出证据清单。

---

## 9. Prompt 模板表 (`prompts/` — 只读文件)

| 字段名 | 数据类型 | 长度 | 可否空 | 注 | 含义 |
|--------|---------|------|--------|-----|------|
| template_name | VARCHAR | 64 | NOT NULL | 文件名 | 模板名称：contract_review/consultation/document_gen 等 |
| system_prompt | TEXT | — | NOT NULL | — | 系统提示词（角色设定） |
| user_prompt_template | TEXT | — | NOT NULL | 含{占位符} | 用户提示词模板 |

**注**：每个模板一个独立文件，系统初始化时加载到内存。模板通过 {变量} 占位符动态填充用户输入与检索结果。

---

## 实体关系总览

```
用户 ──1:N──→ 合同 ──1:N──→ 合同条款（内嵌JSON）
  │
  ├──1:N──→ 咨询记录
  │
  └──1:N──→ 审计日志 ──0:N──→ 合同（记录审查）
                │
                └──0:N──→ 咨询记录（记录咨询）

合同 ──N:M──→ 文书模板（适用/生成）
合同 ──N:M──→ Prompt模板（审查引用）
咨询记录 ──N:M──→ 专题库（专题引用）

计算规则 / 案件与证据指引 / Prompt模板 —— 独立只读资源，无外键关联
```

**总计**：9 张逻辑表，3 张核心业务表（用户/合同/咨询）+ 3 张资源表（模板/专题/规则）+ 1 张审计表 + 2 张辅助表
